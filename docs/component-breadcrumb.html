Breadcrumb

A breadcrumb shows where the current page sits in the site hierarchy and lets users step back up to parent pages.

Usage

  • Use <nav aria-label="Breadcrumb">.
  • Inside, use <ol> with list items.
  • Mark the current page with aria-current="page". If the current page is plain text, add the attribute to the <li>. If it links to itself, add the attribute to the <a>.

Behavior

  • CSS adds chevron separators to every item except the last.
  • The breadcrumb automatically supports right-to-left layouts.
  • The current-page item uses bold text.
