Components

Progress

Minium styles the native <progress> and <meter> elements.

Usage

  • Use <progress> to show the completion of a task, such as an upload or another long-running action.
  • Use <meter> to show a value within a known range, such as quality, health, confidence, or capacity.

Appearance

  • The filled portion of <progress> uses the primary theme color.
  • The color of <meter> reflects its value relative to low, high, and optimum.

Accessibility notes

  • Indeterminate <progress> elements animate unless the user requests reduced motion.
