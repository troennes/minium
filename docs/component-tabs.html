Tabs

Tabs display related navigation links or controls in a horizontal row. An underline marks the current item.

Usage

  • Use <nav class="tabs" aria-label="..."> with a descriptive label.
  • Add an unclassed <ul> containing the tab items.
  • Use links to navigate to separate URLs. Use buttons only when your JavaScript switches content in place.

Accessibility notes

  • The .tabs component does not implement the ARIA Authoring Practices Guide tabs pattern. Link-based tabs provide navigation; button-based panel switching requires additional JavaScript and accessibility behavior.
  • Add aria-current="page" to the current link or button, not to the <li>, so assistive technology announces the current state with the control.
