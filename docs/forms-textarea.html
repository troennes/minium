Textarea

Minium styles native textareas without requiring a component class.

Usage

Add a label to a native <textarea>. The textarea fills the available width, and users can resize it vertically.

Show validation states

Set aria-invalid to false for a valid field or true for an invalid field. Place helper text directly after the field.

Use read-only and disabled textareas

Use a read-only textarea when users can view but not edit its value. Use a disabled textarea when the field is unavailable.

Choose a textarea size

Add .small for a compact textarea or .large for a larger textarea.
