Segmented control

A segmented control is a row of joined options. Users pick one option, or toggle several. It is built from native radio buttons or checkboxes, so it works without JavaScript, submits with the form, and supports the arrow keys.

Usage

  • Add the segmented class to a <fieldset>.
  • Name the group with a <legend>. It appears above the control.
  • Add one <label> per option, with the radio button inside the label.
  • Give all radio buttons the same name, and add checked to the selected one.
View

All segments get the width of the widest one.

Without a visible label

To leave out the legend, use a <div class="segmented" role="radiogroup"> and name the group with aria-label. The default size has the same height as buttons and inputs.

Toggle group

Use checkboxes instead of radio buttons to let users turn on several options.

Format

Sizes

Add small or large next to segmented. The sizes match the button sizes.

Full width

Add the full-width utility to make the control fill its container. The segments stay the same width.

Disabled

Add disabled to an input to disable one option, or to the <fieldset> to disable the whole control.

Plan

Accessibility notes

  • Keyboard support comes from the browser. With radio buttons, Tab moves focus into the group and the arrow keys change the selection. With checkboxes, each option is a tab stop, and Space toggles it.
  • Screen readers announce the options as radio buttons or checkboxes, with the legend or aria-label as the group name.
  • Don't use a segmented control to switch between panels of content. Use tabs instead.
