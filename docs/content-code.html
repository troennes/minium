Code

The typography layer styles inline code, keyboard input, sample output, and code blocks.

Usage

  • Use <code> for inline code fragments and identifiers.
  • Use <kbd> for keyboard shortcuts.
  • Use <samp> for sample output.
  • Wrap code blocks in <pre><code>...</code></pre>.

Run npm run build to generate the production stylesheet.

Press Cmd+K to open quick search.

The terminal returns Build completed successfully.

Code blocks

Code blocks use a separate surface, a monospace font, internal padding, and horizontal scrolling. A code element inside pre does not use the inline chip styling.

.flow > * + * {
  margin-block-start: var(--flow-space);
}

.card {
  --card-padding: var(--space-s-m);
}
<div class="flow">
  <h2>Section title</h2>
  <p>Readable vertical rhythm.</p>
</div>

Syntax highlighting

Code blocks render without syntax highlighting by default. To add syntax highlighting, load the Prism integration with the core stylesheet. See Integrations for setup and theming.
