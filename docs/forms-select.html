Select

Minium styles native <select> elements.

Usage

Pair the <select> with a label and an option list. Single-select fields display the browser's built-in indicator.

Show validation states

Set aria-invalid="false" or aria-invalid="true" to style the select as valid or invalid. Place helper text immediately after the field.

Looks good. Please choose a plan.

Disable a select

Add disabled when users cannot select an option.

Use multiple and grouped options

Add multiple to let users select more than one option. Use <optgroup> to organize a long option list.

Choose a select size

Use .small for a compact select or .large for a larger select.
