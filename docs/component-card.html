Components

Card

A card groups related content and actions in a bordered container with built-in vertical spacing.

Usage

  • Add class="card" to an <article>, <section>, or <div>.
  • Place content as direct children of the card to apply automatic spacing.
  • Customize the card padding with --card-padding.

Link cards

To make the entire card clickable, apply .card to an <a> element. Link cards provide hover and active feedback without applying link styling to their text.

Link card

Accessibility notes

  • .card is a visual component; it does not add semantics by itself.
  • Prefer article for standalone, reusable content, section for a labeled page section, and div for purely visual grouping.
  • Do not nest links, buttons, or other interactive elements inside a link card.
