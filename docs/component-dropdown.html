Dropdown

A dropdown is a button that opens a floating panel of actions or links. It uses the native Popover API and CSS anchor positioning, with no JavaScript required. Minium does currently not provide fallbacks for browsers without support for these features. Add polyfills if your project supports those browsers.

Usage

  • Wrap the dropdown in a container with class="dropdown".
  • Add a trigger <button> with popovertarget="menu-id".
  • Add a panel with id="menu-id" and the popover attribute. Place a list of links or buttons inside it.

Borderless

Add .border-none to remove the trigger button's border and shadow. This modifier works well for icon-only triggers and triggers within navigation.

Alignment

Use a modifier class to control the panel's inline alignment:

  • Default: aligns to the right edge of the trigger.
  • .left: aligns to the left edge of the trigger.
  • .center: centers the panel under the trigger.

Panels use position-try-fallbacks to change their block or inline position when necessary to remain within the viewport.

Width

Custom properties control the panel width. Set them inline, in project.css, or on an ancestor to size one or more dropdowns without a modifier class.

  • --dropdown-width sets the panel's inline-size. The default is max-content.
  • --dropdown-min-width sets the panel's min-inline-size. The default is 12rem.
  • --dropdown-max-width sets the panel's max-inline-size. The default is calc(100% - var(--space-s-l)).

Nested dropdowns

Place a .dropdown inside another dropdown panel to create a nested dropdown. The nested panel opens beside its parent menu from the top-right of its trigger.

Accessibility notes

  • Minium dropdowns are native popovers, not full ARIA menu buttons. They do not implement the ARIA Authoring Practices Guide menu button pattern. That pattern requires role="menu", aria-expanded, and JavaScript-based focus management.
  • Keyboard users can open the popover with Enter or Space, move through its items with Tab, and close it with Escape or light dismiss. Dropdowns do not provide arrow-key navigation.
  • If the panel contains navigation links, use <nav> and provide an aria-label. For action lists and other content, use a generic container such as <div>.
  • Give each icon-only trigger an accessible name, such as an aria-label. Add aria-hidden="true" to its decorative SVG.
