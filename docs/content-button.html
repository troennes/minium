Button

Minium styles button controls with minimal markup.

Usage

  • Use <button> without classes for the primary button style.
  • Use .secondary or .tertiary for a lower-intensity button.
  • Choose a semantic variant: .accent, .danger, .success, .warning, .info, .contrast, or .neutral.
  • Use .small or .large to change the button size.
<button class="secondary">Secondary</button>
<button class="tertiary">Tertiary</button>
<button class="accent">Accent</button>
<button class="danger">Danger</button>
<button class="success">Success</button>
<button class="warning">Warning</button>
<button class="info">Info</button>

<button class="small">Small</button>

Add an icon to a button

A button can contain an inline SVG icon and text. Add .icon to the SVG to apply the correct size and alignment.

<button><svg class="icon" ... ></svg> Add item</button>
<button class="secondary"><svg class="icon" ... ></svg> Filter</button>
<button class="accent"><svg class="icon" ... ></svg> Download</button>

<button data-tooltip="Search" aria-label="Search"><svg class="icon" ... ></svg></button>
<button class="secondary rounded" data-tooltip="Favorite" aria-label="Favorite"><svg class="icon" ... ></svg></button>
<button class="accent rounded" data-tooltip="Settings" aria-label="Settings"><svg class="icon" ... ></svg></button>

Create an icon-only button

Use .icon-only to apply square padding, a transparent surface, and a tinted hover background. Add an aria-label that describes the action. Add .rounded for a circular button. Use .close to add an X icon with ::before; this preset does not require inner markup.

<button class="icon-only" aria-label="Search"><svg class="icon" ... ></svg></button>
<button class="icon-only rounded" aria-label="Settings"><svg class="icon" ... ></svg></button>
<button class="close" aria-label="Close"></button>

Use a link as a button

Link button Accent link button 
<a href="#" role="button">Link button</a>
<a href="#" role="button" class="accent secondary">Accent link button</a>

Use buttons and inputs in a form

Inside forms, buttons are full width by default. Outside forms, use the .full-width utility to make a button fill its container.

Group buttons

Use role="group" for a tightly related set of controls. Use .cluster for toolbar-style actions that can wrap with wider spacing.
