Alert

An alert is an inline message that draws attention to a confirmation, warning, error, or other status update.

Usage

  • Add class="alert" to a container.
  • Use a variant class to set context: .primary, .accent, .info, .warning, .success, or .danger.

Dismissible alert

Add a .close button as a direct child of the alert. The button docks in the top inline-end corner, and the alert reserves space for it. Add JavaScript to dismiss the alert because alerts have no native close behavior.

A .close button nested inside a wrapper, such as a .repel header row, remains in normal flow and does not dock in the corner.

<div class="alert warning">
  <h3>Storage almost full</h3>
  <p>You have used 95% of your quota. Older exports will be deleted first.</p>
  <button class="close" aria-label="Dismiss" onclick="this.closest('.alert').remove()"></button>
</div>

Accessibility notes

  • .alert is a visual component; it does not imply an ARIA alert.
  • Place the .close button last in the markup so assistive technologies read it and keyboard users reach it after the alert content. Give the button an accessible name, such as aria-label="Dismiss".
  • Add role="alert" only for urgent, time-sensitive messages that appear or update after user action.
  • Prefer role="status" or aria-live="polite" for non-urgent updates.
  • When severity matters, include a visible label such as “Error”, “Warning”, or “Success”.
