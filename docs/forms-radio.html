Radio

Minium styles native radio inputs.

Usage

Use radio buttons when users can select one option from a set. Give every radio input in the group the same name.

Create a horizontal radio group

To create a horizontal group, place each label immediately after its radio input. Minium styles this adjacent input + label pattern inline.

Plan

Group related radio buttons

Use fieldset to group related radio buttons and legend to name the group.

Billing cycle

Show validation states

Set aria-invalid="true" when the selection fails validation. Use aria-invalid="false" only when you need to expose an explicit valid state.
