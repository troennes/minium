Components

Badge

Use badges and pills to display compact status, count, or metadata labels alongside other content.

Usage

  • Use .badge for labels with rounded corners.
  • Use .pill for fully rounded labels.
  • Apply .primary, .accent, .info, .success, .warning, .danger, or .muted to either .badge or .pill.

Accessibility notes

  • Use span for static labels, a for links, and button for actions.
  • Hide decorative icons inside badges with aria-hidden="true".
  • For rows of interactive badges, use .cluster to add consistent spacing between controls.
