Modal

The modal component styles the native <dialog> element for modal and non-modal content. It includes a backdrop, flow spacing, and optional header and footer sections.

Usage

The following examples cover modal and non-modal dialogs, corner close controls, and structured content.

Modal dialog

Use showModal() to open a modal dialog. The rest of the page becomes inert, and focus remains inside the dialog.

Greetings, one and all!

Non-modal dialog with the Popover API

Add popover to create a non-modal dialog that opens through popovertarget without JavaScript. The page remains interactive, and focus can leave the dialog. Use this pattern for lightweight, dismissible content.

Greetings, one and all!

Corner close button

Place a .close button last among the dialog's direct children to position it in the top inline-end corner. The dialog reserves space so that its title does not extend beneath the button. If an <article> wraps the dialog content, keep the close button outside that wrapper.

You do not need JavaScript to close the dialog. For a modal dialog, wrap the button in <form method="dialog">. For a popover dialog, set popovertarget and popovertargetaction="hide" on the button.

Greetings, one and all! This dialog opens and closes without any JavaScript.

Structured modal

Use <header> and <footer> to divide a dialog into structured sections with consistent padding. This example uses showModal() and gives the dialog an accessible name through aria-labelledby. A <form method="dialog"> closes the dialog without additional JavaScript.

Accessibility notes

  • Give every dialog an accessible name with aria-labelledby pointing at a visible title, or aria-label when there is no visible title.
  • Minium locks page scrolling while a popover dialog is open. This visual effect does not make the rest of the page inert.
  • Place the corner .close button, or its wrapping form, after the dialog content so that it occurs later in the reading and tab order. Give an icon-only button an accessible name, such as aria-label="Close".
