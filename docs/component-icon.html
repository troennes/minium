Icon

The .icon component sizes an inline SVG to match the surrounding text and aligns it with the text baseline. Minium does not include an icon set.

Usage

  • Add .icon to an inline SVG.
  • Use currentColor when the icon should inherit the text color.
  • Use .small or .large only when the icon should differ from the surrounding text size.

Default icon follows the surrounding text.

Small icon and large icon do not match the surrounding text size. 

<p>
  Default icon
  <svg class="icon" aria-hidden="true" ...></svg>
  follows the surrounding text.
</p>

<p>
  Small icon <svg class="icon small" aria-hidden="true" ...></svg>
  and large icon <svg class="icon large" aria-hidden="true" ...></svg>
  do not match the surrounding text size.
</p>

Text-relative sizing

A plain .icon is a 1em square, so it scales with the surrounding text.

Body text uses the default size.

Small text uses a smaller icon automatically.

Lead text uses a larger icon automatically.

Scoped overrides

Set --icon-size and --icon-align when an icon requires custom sizing or alignment. These custom properties inherit, so set them on the icon unless every icon in a wrapper should share the override.

<button style="--icon-size: 1.25em; --icon-align: -0.2em;">
  <svg class="icon" aria-hidden="true" ...></svg>
  Custom
</button>

Accessibility notes

  • Use aria-hidden="true" for decorative icons next to visible text.
  • If a meaningful icon has no adjacent visible label, give it an accessible name with aria-label or an SVG <title>.
  • For icon-only buttons, label the button itself. See the Button documentation for the complete pattern.
