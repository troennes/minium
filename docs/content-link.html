Link

Links retain native link behavior and support visual variants for different levels of emphasis.

Usage

  • Use an <a> element with an href attribute for links.
  • Use .secondary, .tertiary, .accent, or .neutral to adjust the visual treatment.

Choose a link variant

  • .secondary and .tertiary reduce the default link emphasis.
  • .tertiary hides the underline until the link receives hover or focus.
  • .accent changes the link decoration color, while .neutral inherits the surrounding text color.
