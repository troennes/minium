Table

The base typography layer styles semantic tables. Captions use muted italic text, while header and footer rows use stronger separators.

Usage

Use <caption>, <thead>, <tbody>, and <tfoot> when they describe the table's content.

Apply table modifiers

Use the following modifiers to adjust table presentation:

  • Use .striped to add alternating backgrounds to body rows.
  • Use .centered to center cell content.
  • Use .border-none to remove cell borders.

Make a table full width

By default, a table uses the natural width of its content. Add .full-width to make the table fill its container.

Add horizontal scrolling

When a table is wider than its container, wrap it in a <div class="overflow-x"> to enable horizontal scrolling:

<div class="overflow-x">
  <table>...</table>
</div>

The wrapper handles overflow without changing the table's native layout. Column sizing, sticky headers, and other table features continue to work as expected.

Use .full-width when a table should fill its container. Use .overflow-x when a table may exceed the available width. These utilities solve different problems and usually do not need to be combined.
