Switch

Minium styles native <input type="checkbox" role="switch"> controls without requiring a component class.

Usage

Use a switch for a binary setting that takes effect immediately.

Group related switches

Use a fieldset and legend when several switches belong to one settings group.

Privacy

Create a horizontal switch group

To create a horizontal group, place each input immediately before its label (input + label).

Workspace settings

Show validation states

Set aria-invalid="true" when the switch state fails validation. Use aria-invalid="false" only when you need to expose an explicit valid state.

Disable a switch

Add disabled when users cannot change the switch state.
