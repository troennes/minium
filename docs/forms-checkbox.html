Checkboxes

Minium styles native checkboxes without requiring a component class.

Usage

Wrap a native <input type="checkbox"> in a label to associate the control with its text.

Create a horizontal checkbox group

Place each input immediately before its label. The CSS targets this input + label pattern.

Channels

Group related checkboxes

Place related checkboxes in a fieldset, and describe the group with a legend.

Notification channels

Show validation states

Set aria-invalid to false for a valid checkbox or true for an invalid checkbox.

Show an indeterminate state

Use the indeterminate state when a parent checkbox represents a partially selected group. Set the input's indeterminate property to true with JavaScript.

Disable a checkbox

Disable a checkbox when users cannot change its value.
