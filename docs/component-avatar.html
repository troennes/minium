Avatar

An avatar represents a user or entity with a photo or fallback initials.

Usage

  • Add class="avatar" to a <figure>.
  • Add text for fallback initials.
  • Use .small or .large to change the avatar size.
  • If the built-in sizes do not meet your needs, set --avatar-size to a custom size.

Image avatars

Place an <img> directly inside the avatar. The image fills the avatar and uses object-fit: cover to crop when necessary.

Shape variants

Add .square or .squircle to change the avatar shape.

Avatar groups

Wrap avatars in an element with role="group" to overlap them and display a separating ring around each avatar.

Media object pattern

Combine .avatar with .sidebar.media to create a profile row containing an avatar, name, and one-line description.

Accessibility notes

  • If the visible name is nearby, use alt="" or aria-hidden="true" to avoid duplicate announcements.
  • If the avatar is the only visible identity, provide the full name with alt or aria-label.
  • For avatar groups, provide a group label or accessible names for the individual avatars.
