Tooltip

A tooltip displays a short message when the user hovers over or focuses an element. This component uses CSS only.

Usage

Add data-tooltip="…" to the target element. Set its value to the tooltip text.

The following examples add tooltips to an inline element and a link.

Non-interactive inline elements use a dotted underline by default.

Tooltips appear above the target by default. Set data-placement to right, bottom, or left to change the placement.

<button data-tooltip="Top" data-placement="top">Top</button>
<button data-tooltip="Right" data-placement="right">Right</button>
<button data-tooltip="Bottom" data-placement="bottom">Bottom</button>
<button data-tooltip="Left" data-placement="left">Left</button>

Tooltips appear on hover and :focus-visible.

Accessibility notes

  • The data-tooltip attribute is visual only. Add an aria-label to expose the text to assistive technologies.
  • For non-interactive elements, add tabindex="0" so keyboard users can focus the element and display its tooltip.
  • Long tooltip text can overflow the viewport near its edges.
