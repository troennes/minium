Navbar

A navbar groups your brand, primary navigation, and actions in a single horizontal bar.

Usage

  • Place the <nav> as a direct child of a <header>. Outside a header, add the .navbar class instead.
  • Organize the brand, navigation links, and actions into one or more direct child <ul> elements without classes.
  • The nav itself behaves like .repel, and each direct child <ul> behaves like a horizontal .cluster.
  • Use links or links styled as buttons inside the list items.

Outside a header

For a <nav> that is not a direct child of a <header>, add the .navbar class to enable the navbar layout.

Keep a navbar visible

Add .sticky to keep a navbar at the top of its scroll container. For the semantic navbar pattern, add the modifier to the containing <header>. For a standalone nav.navbar, add the modifier to the <nav>.

<header class="sticky">
  <nav class="container">...</nav>
</header>

<nav class="navbar sticky">...</nav>

Behavior and constraints

  • This pattern is intended for header-style navigation, not side menus, breadcrumbs, or pagination.
  • If a page header uses a .container, apply the class to the <nav> so that the <nav> remains a direct child of the <header>.
  • A <nav> outside a <header> without .navbar uses only the shared navigation styles: no list markers and inherited link color. Use this configuration as a neutral starting point.
