Skeleton

Skeletons represent content while it loads.

Usage

  • Add .skeleton and one shape modifier: .line, .box, or .circle.
  • Mark placeholders with aria-hidden="true".
  • Set aria-busy="true" on the region being updated. Remove the attribute when the content loads.

Loading content pattern

Combine skeletons with layout primitives to match the final content structure.

Notes

  • .line spans the available width by default.
  • .box and .circle use fixed dimensions by default. Override their dimensions with an inline style or project CSS.
  • Minium disables the shimmer animation when the user requests reduced motion.
